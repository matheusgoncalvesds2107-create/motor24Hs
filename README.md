# Motor 24H — Aplicativo Windows

Projeto pronto para gerar um `.exe` instalável e também uma versão portátil.

## O que faz
- Toca a grade da Web Rádio Vem Comigo Deus 24h.
- Fora dos programas, toca a pasta de louvores.
- Nos horários dos programas, usa abertura, Palavra, mensagem de fé e encerramento.
- Envia o áudio direto para o Caster/SapirCast.
- Não depende do Render para montar a programação.
- Guarda a senha SOURCE localmente no Windows.
- Pode iniciar automaticamente ao abrir.

## Gerar o EXE automaticamente no GitHub
1. Crie um repositório ou envie estes arquivos para um repositório.
2. Abra a aba Actions.
3. Execute `Build Motor 24H Windows EXE`.
4. Ao terminar, baixe o artifact `Motor-24H-Windows-EXE`.
5. Dentro dele estarão o instalador `.exe` e a versão portátil `.exe`.

## Primeiro uso do aplicativo
No próprio app escolha:
- pasta dos louvores;
- pasta dos programas;
- host/porta/mount do Caster;
- usuário SOURCE;
- senha SOURCE.

Não publique nem envie a senha SOURCE pelo chat.
